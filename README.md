# Aim:
To identify user pain points, formulate UX problem statements, select appropriate UX research methods, and create user personas for two different UX project scenarios.

# Algorithm:
Select two different UX project scenarios.
Identify the target users and their major pain points.
Write 1–2 UX problem statements using the given template.
Identify suitable UX research methods for each scenario.
Justify why the selected research methods are appropriate.
Create at least two user personas for each scenario.
Include demographics, goals, behaviours, pain points, and motivation in each persona.
Analyse the findings and identify the key UX requirements.

# Result:
Two UX project scenarios were analysed successfully by identifying user pain points, developing problem statements, selecting suitable research methods, and creating user personas. The findings can be used to develop more user-centred and effective designs.
